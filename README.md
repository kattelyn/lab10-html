# Лабораторна робота №10 — Шевчук Катерина, 305-ТН

Відкрийте `index.html` у браузері або опублікуйте кореневі HTML-файли через GitHub Pages.

- `float.html` — розмітка через CSS float.
- `flexbox.html` — розмітка через Flexbox.
- `grid.html` — розмітка через CSS Grid.
- `express/` — додаткове завдання Node.js + Express.

Адаптивність: до 499 px, від 500 px, від 750 px, від 950 px, від 1200 px.

Для запуску Express: у папці `express` виконати `npm install`, потім `npm start`. Відкрити http://localhost:3000. GitHub Pages не запускає Node.js-сервер, але статичні сторінки працюють окремо.
